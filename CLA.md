## Maintainer setup

1. Install the [CLA Assistant](https://cla-assistant.io) GitHub App on the
   `FreePeak/db-mcp-server` repository and grant it access to this repository.
2. In the app's settings for this repository, link this document
   (`CLA.md` on `main`, or a gist of it) as the CLA to sign.
3. Configure the bot allowlist to include `dependabot[bot]` and `github-actions[bot]`.
4. In the repository's branch protection rules for `main`, make the CLA Assistant
   status check a required status check.
